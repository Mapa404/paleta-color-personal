# Tu paleta de color

Análisis de color personal según el sistema de las 12 estaciones. La persona sube una foto, marca piel, ojos y pelo, y obtiene su estación, su paleta, neutros, colores para evitar, combinaciones y una prueba de colores sobre su cara.

- Todo se procesa en el navegador: la foto no se sube a ningún servidor ni se guarda.
- HTML, CSS y JavaScript sin dependencias ni build.

## Correr en local

Abrir `index.html` en el navegador o servir la carpeta con cualquier servidor estático.

## Dependencias

- `vendor/jspdf.umd.min.js`: [jsPDF](https://github.com/parallax/jsPDF) 2.5.2 (licencia MIT, ver `vendor/jspdf-LICENSE.txt`), para generar el PDF del resultado en el navegador. Está incluida en el repo para no depender de CDNs externos.
